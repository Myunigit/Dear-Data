# Dear-Data
My dear data project for my creative coding module
# Topic: My gaming habits
I will be tracking my habits when playing online games
The attributes of data I am currently collecting for each match are as follows:
- Date
- Time
- How many people I am playing with
- The game mode the match is in
- The character I am using
- My accuracy
- Whether I win or lose
- My KDA (Number of kills, deaths and assists)
- Match length
- My mood during the match
More data attributes may be retroactively collected
